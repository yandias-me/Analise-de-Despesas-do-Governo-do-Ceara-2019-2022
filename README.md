# Analise-de-Despesas-do-Governo-do-Ceara-2019-2022
Este Projeto tem como finalidade apresentar uma análise geral das despesas do governo do estado do ceará de 2019 até 2022 e mostrar todo o passo a passo da criação do modelo de Data Warehouse gerado a partir do backup de dados iniciais desde o ETL, modelagem do tipo Star Schema no PostgresSQL até o relatório final no Power BI
